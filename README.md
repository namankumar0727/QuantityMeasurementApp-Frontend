# QuantityMeasurementApp-Frontend

## UC-19 : Quantity Measurement App – Frontend Development  
---

This repository contains the **frontend implementation** of the Quantity Measurement Application, designed to provide an interactive and user-friendly interface for unit operations. The frontend is built using both **Vanilla Web Technologies** and the **Angular Framework**, ensuring flexibility and scalability.

## ⚙️ Core Functionalities  

- 📏 Unit comparison  
- 🔄 Unit conversion  
- ➕ Arithmetic operations on quantities  
- 🎯 Dynamic and responsive UI  

## ✨ Features Implemented  

### 🎨 UI & User Experience  
- Clean and intuitive interface  
- Responsive design for multiple devices  
- Dynamic UI updates based on user input  

### ⚡ Frontend Logic  
- Event-driven architecture  
- Real-time calculations and updates  
- Input validation and error handling  

### 🔗 API Integration  
- Fetch API for backend communication  
- JSON Server integration (mock backend)  
- Seamless data flow between frontend and backend  

### 🧩 Development Approaches  
- Vanilla HTML, CSS, JavaScript implementation  
- Angular-based scalable architecture  
- Modular and reusable components
